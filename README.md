# Better Phantoms

This repository keeps both supported development tracks in one place:

- `mc-1.21.1/` contains the NeoForge `1.21.1` implementation.
- `mc-26.1.2/` contains the NeoForge `26.1.2` implementation.

Build commands:

- `mc-1.21.1\\gradlew.bat build`
- `mc-26.1.2\\gradlew.bat build`

Run commands:

- `mc-1.21.1\\gradlew.bat runClient`
- `mc-26.1.2\\gradlew.bat runClient`

Notes:

- Keep gameplay fixes version-scoped unless you intentionally backport them.
- Root-level docs and CI are shared across both version folders.

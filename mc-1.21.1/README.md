# Better Phantoms

This folder contains the Minecraft `1.21.1` NeoForge implementation of Better Phantoms.

## Target

- Minecraft `1.21.1`
- NeoForge `21.1.x`
- Java `21`

## Requirements

- Use this folder for the `1.21.1` release line.
- Keep fixes here version-scoped unless you intentionally backport from another target.

## Configuration

Common config file:

`run/config/betterphantoms-common.toml`

Main options include:

- Overworld spawn disable toggle
- Insomnia spawn disable toggle
- Dragon fight wave toggle, size range, cap, and frenzy duration
- Post-dragon End spawning toggle and weights
- Patrol altitude and End City dive pressure tuning
- Elytra repair effectiveness
